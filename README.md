## 更新游戏版本

1. 在游戏仓库中构建最新安装版 EXE。
2. 将文件放入本仓库的 `downloads/` 目录。
3. 更新 `index.html` 中版本标签、下载路径、文件大小和 SHA-256。
4. 提交并推送本仓库，由 GitHub Pages 直接提供下载，不创建 GitHub Release。
